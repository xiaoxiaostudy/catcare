# 猫咪知识笔记库

这是你的笔记库总目录和工具箱：放模板、各主题的进度、来源清单、两张核对清单，以及绵绵和妙妙的档案。每个主题的正式笔记按模板写，写完回到这里更新状态。

状态标记：**未开始 / 写作中 / 已完成 / 已审核**（已审核指兽医看过）。

## 一、笔记模板

每个主题复制一份，按下面十栏填写：

1. 一句话结论
2. 为什么（机制，简单讲清楚）
3. 早期信号
4. 就医红线
5. 家里能做什么
6. 常见误区
7. 国内差异（待核对 / 已核对）
8. 来源（每条关键结论至少一个权威来源，数值必须注明出处）
9. 存疑点（待问兽医，同时记入第四部分的清单）
10. 我家猫的实际情况（绵绵、妙妙）
