## 1. 为什么要刷牙（带出处）

- **刷牙是保持牙齿和牙龈健康最好的办法**：能防止牙菌斑和牙结石形成，让牙龈更健康，减少口臭（iCatCare）。
- **每天刷能预防大多数牙病**（Cornell）。
- 牙病在猫里很常见，尤其是老猫，会让猫吃不下、很疼（Cornell），见《牙周病和口炎》。
- 有的猫天生更容易得牙病，但在家坚持护理能改善牙齿健康，减少需要麻醉洗牙、拔牙的次数（iCatCare）。

## 2. 用什么刷

| 用品 | 要点 |
| --- | --- |
| 牙刷 | 猫用牙刷；**家里每只猫一把**，免得通过口水互相传染（iCatCare） |
| 牙膏 | **只用猫专用牙膏**，有鸡肉、牛肉、鱼等口味，可以试试猫喜欢哪种；**人的牙膏绝对不能用**，猫不爱吃，还可能刺激胃（iCatCare），对猫不安全（Cornell） |
| 指套牙刷 | iCatCare 建议谨慎使用，多数情况下最好不用，免得被咬 |
| 奖励 | 零食，或者让它从最喜欢的水龙头喝水（Cornell） |

可以查兽医口腔健康委员会（VOHC）认可的产品（iCatCare）。

## 3. 早期信号：刷牙时看什么

- **刚开始刷时牙龈有一点出血**：很常见，规律刷下去、牙龈变健康后会停（iCatCare）。
- **一直出血、牙龈红肿、口臭、流口水、用爪子抓嘴、吃饭时歪头**：可能是牙病，见《牙周病和口炎》。
- **牙齿和牙龈交界处有粉红色的缺损**：可能是牙吸收，常常很疼（Cornell）。

## 4. 就医红线

- **有牙病的信号**：约兽医，先治疗再刷（iCatCare）。已经有严重牙龈炎的猫，刷牙会很疼（Cornell）。
- **刚洗过牙、拔过牙**：等嘴巴长好再开始在家护理（iCatCare）。

## 5. 家里能做什么

**iCatCare 的分步法**（每一步猫都舒服了再进下一步，每步花几天也没关系）：

1. **习惯被摸头和嘴**：从温柔地抚摸开始，慢慢到它愿意让你掀起嘴唇露出牙齿。每次都用它最喜欢的零食结束。
2. **尝牙膏**：把牙膏挤在手指上让它舔；不喜欢就换口味。
3. **练习扶头**（在它放松时练，和刷牙不在同一时间，一天可以练几次）：
   - 让猫背对着你，这样它不觉得被对峙，挣扎时也是往后退，更好控制。
   - 手掌放在猫头顶偏后的位置，拇指和中指轻轻扶住眼睛下方的颧骨，食指抬起来，不要挡住眼睛。
   - 头稍稍往上抬，用拇指掀起上唇，另一只手把下唇轻轻往下拉，就能看到一边的牙。
   - 猫不舒服就停，第二天再试。
4. **用棉签**：接下来几天用同样的姿势，把牙膏涂在棉签上，在牙齿上轻轻画圈。**从后面的牙开始**，它们最难够到，却最重要，再慢慢往前。
5. **用牙刷**：同样从后牙开始，小幅画圈。每边先刷 10 秒，慢慢增加到 30 秒。

**Cornell 的四周训练法**：

| 第几周 | 做什么 |
| --- | --- |
| 第 1 周 | 熟悉牙膏的气味：把牙刷牙膏放在猫能闻到的地方；每天在手指上挤一点让它闻、舔，舔了就奖励 |
| 第 2 周 | 熟悉牙膏的味道：每天在一颗犬齿上点一点牙膏，然后奖励 |
| 第 3 周 | 熟悉牙刷：牙刷上放一点牙膏让它舔，然后奖励 |
| 第 4 周 | 轻轻拉开嘴唇，把牙刷伸到嘴唇和牙龈之间，刷毛和牙齿成 45 度，对准牙齿和牙龈之间的缝，上下牙都刷一圈 |

**只刷外侧就够了**：猫自己的舌头能把内侧清理得很好（Cornell）。

**养成习惯**（iCatCare）：选一个固定的时间。可以吃完饭刷，也可以刷完用食物奖励，怎么适合你和猫都行。目标是让刷牙成为愉快的事，不是一场战斗。

**实在不让刷**（iCatCare）：

- 猫用洁牙零食：能减少但不能防止牙菌斑和牙结石，问兽医哪种合适。
- 如果猫喜欢牙膏的味道，把牙膏抹在干粮或洁牙零食上，让它嚼的时候蹭到牙齿。
- 兽医可能建议牙科处方粮。
- 有的宠物医院有护士可以示范怎么刷。

## 6. 常见误区

- **用人的牙膏也行**：绝对不行（iCatCare、Cornell）。
- **成年猫没刷过，学不会了**：任何年龄都可以开始，只是要更多时间和耐心（iCatCare）。
- **刷牙要把里外都刷到**：只刷外侧就够了（Cornell）。
- **牙龈出血就不能刷了**：刚开始有一点出血很常见，规律刷会好；但一直出血或有牙病要先看兽医（iCatCare、Cornell）。
- **吃洁牙零食就不用刷牙**：零食只能减少，不能防止牙菌斑（iCatCare）。
- **不麻醉洗牙更安全**：AAFP 生命阶段指南说不麻醉洗牙不合适，压力大、可能受伤、可能误吸，也查不出问题，只清了看得见的表面。

## 7. 国内差异

待核对：国内能买到的猫用牙膏、牙刷，有没有 VOHC 认证；国内宠物医院麻醉洗牙的流程和费用。
