## 记住这三件事

1. **先找「全价」。** 全价粮才有猫需要的全部营养。标着「补充」「间歇」「短期」喂养的，只能占每天的一成以内（WSAVA）。
2. **再看适合哪个阶段。** 生长期、成年、繁殖期，营养标准不一样（WSAVA、Cornell）。
3. **「天然」「优质」可以直接跳过。** 这些词没有监管，是用来卖货的，看不出营养（WSAVA）。

## 怎么看一包猫粮

按这个顺序，在包装上找：

1. **营养声明**：写没写「全价」，适合哪个阶段。标「适合所有生命阶段」的粮，是按繁殖期和生长期的需要配的（WSAVA、Cornell）。
2. **热量**：每克或每份多少千卡，算喂多少要用。只有美国强制要求标；没标的可以问厂家（WSAVA）。知道热量以后，可以用[喂多少](/catcare/notes/feeding-water/)里的计算器算克数。
3. **配料表的前几位**：最好是肉、肉类副产品或海产品（Cornell）。
4. **厂家信息**：有没有电话或邮箱，写的是「生产商」还是「为……生产」「经销」（WSAVA）。

买回来以后，粮合不合适要看猫：体重和体型一直往一个方向变，见[猫的体型评分怎么看](/catcare/notes/body-condition/)；换粮后呕吐、拉肚子，换粮要慢慢来，见[猫是肉食动物](/catcare/notes/carnivore/)。

## 配料表能看出什么

| 能看出 | 看不出 |
| --- | --- |
| 放了哪些东西 | 原料的质量 |
| 按重量从多到少的顺序（Cornell） | 「无谷」是不是就低碳水：不一定（Merck） |
| 前几位是不是肉，动物原料够不够（Cornell） | 厂家靠不靠谱：要另外问（WSAVA） |

好记的说法：**配料表是「放了什么」，不是「好不好」。**

## 拿不准时，问厂家四个问题

WSAVA 建议问这四个。**厂家不能或不愿意回答，就要谨慎喂这个牌子。**

1. **有没有营养学家？** 最好是全职的，动物营养学博士，或者有 ACVN、ECVCN 认证。
2. **谁设计配方？** 是营养学背景的配方师或兽医，还是宠物主人、繁育者？
3. **怎么做质量控制？** 对成品做过营养化验吗？原料、细菌、保质期有没有检测？
4. **做过、发表过营养研究吗？** 不是必须，但做了说明它重视动物健康。

## 这些情况问问兽医

- **吃处方粮的猫**：处方粮要在兽医指导下喂（WSAVA、Merck）。别自己换成普通粮，也别自己给健康的猫吃处方粮。
- **不知道该选哪种粮**：兽医可以推荐适合你家猫的（Merck）。

## 别这样做

- **看到「天然」「优质」就当好粮**：这些词没有监管（WSAVA）。
- **配料表第一位是肉就放心**：看不出原料质量，还要看营养声明和厂家（WSAVA、Cornell）。
- **把「无谷」当成低碳水**：不一定（Merck）。
- **觉得生肉粮、低温熟制粮更健康**：Cornell 说没有科学证据证明有好处，还可能带有能传给猫和人的细菌、病毒、寄生虫，不推荐。
- **把补充罐当主食**：标着「补充」的不是全价粮，只能占一小部分（WSAVA）。
- **零食给太多**：每天零食控制在热量的 10% 到 15% 以内（Cornell）；不全价的食品，WSAVA 说不超过 10%。

## 考考自己

1. 一罐湿粮写着「补充喂养」，你打算每顿都给，当主食。行吗？
   - 不行。补充喂养的不是全价粮，只能占每天的一成以内（WSAVA）。
2. 一包粮的配料表第一位是鸡肉，是不是就是好粮？
   - 不一定。配料表只说明放了什么、按重量排的顺序，看不出原料质量（WSAVA、Cornell）。还要看营养声明和厂家。
3. 「无谷」猫粮，碳水就低吗？
   - 不一定（Merck）。
4. 你发邮件问厂家有没有营养学家，对方不回答。怎么办？
   - WSAVA 说，厂家不能或不愿意回答这些问题，就要谨慎喂这个牌子。

## 细节：标签上的规定和出处

| 看什么 | 为什么 | 出处 |
| --- | --- | --- |
| 营养充足声明：全价还是不全价 | 全价粮才包含猫需要的全部营养。标着「短期」「间歇」或「补充」喂养的，只能占饮食的 10% 以内，或者在兽医指导下喂（比如处方粮） | WSAVA |
| 适合哪个生命阶段 | 营养标准分繁殖、生长、成年三种；标「适合所有生命阶段」的粮，是按繁殖和生长期的需要配的 | WSAVA、Cornell |
| 每克或每份的热量 | 防止不小心喂多。只有美国要求标热量；没标的可以问厂家，或者根据营养成分计算 | WSAVA |
| 厂家联系方式 | 应该有电话或邮箱，方便问标签上没写的营养素含量；厂家应该能提供所有必需营养素的「典型」分析值 | WSAVA |
| 谁生产的 | 写「生产商」是厂家自己做的；写「为……生产」或「经销」是找别的工厂代工 | WSAVA |

在美国，宠物食品必须标明营养充足声明，写清楚它为哪个生命阶段提供完整均衡的营养；达不到标准的，只能标成零食或「偶尔喂」（Merck）。Cornell 说带有美国饲料管理协会（AAFCO）营养保证声明的猫粮，都算营养完整均衡。

问厂家的四个问题，WSAVA 原文更细：营养学家的资质是动物营养学博士，或美国兽医营养学会（ACVN）、欧洲兽医比较营养学会（ECVCN）认证，外聘顾问的影响力可能有限；配方师最好是动物营养学硕士或博士；质量控制包括配方是按营养数据库算的还是对成品化验过，生产前、中、后有没有做原料验证、成品营养分析、毒理、细菌、包装和保质期检测。

Merck 说，知名品牌通常有科学研究和质量控制做支撑。
