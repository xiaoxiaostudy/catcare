## 记住这三件事

1. **猫不舒服时，很少喊疼。** 它的祖先独来独往，把病痛藏起来才活得下去（PMC、Texas A&M）。
2. **要看的是「跟平时比，变了没有」。** 变化往往很小：换了地方睡、不跳了、躲起来了。
3. **变了又找不到原因，就带去看兽医。** 跟兽医一起找原因（Texas A&M）。

## 要留意哪些变化

好记的说法：**睡、梳、跳、躲、盆、叫、吃**，七个字。

| 看什么 | 变成这样要留意 |
| --- | --- |
| 睡 | 睡得多了或少了；换了睡觉的地方、姿势；躺下后老是找不到舒服的姿势 |
| 梳 | 梳毛少了；或者老在一个地方舔、咬、抓 |
| 跳 | 不爱跳了，跳得没以前高；走路僵，不爱上下楼梯，懒腰伸得少了 |
| 躲 | 大部分时间躲在床底、衣柜里；不愿意被摸 |
| 盆 | 用砂盆少了，尤其是边很高的砂盆 |
| 叫 | 叫得多了，表情怪 |
| 吃 | 吃得、喝得跟平时不一样 |

来源是 Texas A&M 和 PMC 的文章，完整的表见下面的「细节」。

## 怎么看出它变了

- **先记下它平时的样子**：睡在哪、什么姿势，什么时候爱梳毛，几点最活跃，能跳多高，跟人、跟别的猫怎么相处。
- **每周对比一次**，写下哪些跟平时不一样。「[我的猫](/catcare/cats/)」里每天的记录可以帮你对比。
- **每月拍一段视频**：同一个地方，拍它走路、跳上跳下。以后好对比，也能给兽医看。这是我的建议，不是来源原话。
- **它不爱用砂盆了**：看看砂盆的边是不是太高（Texas A&M）。

## 这些情况问问兽医

- **看到上面这些变化**：带它去看兽医，一起找是哪里疼、怎么治最合适（Texas A&M）。
- 来源没说「变了多久就要去」。网上有些诊所博客写了 24 到 48 小时这类数字，但找不到可靠出处，没有采用。

更急的情况，比如公猫尿不出、一天不吃，看[吃喝拉撒](/catcare/notes/eating-drinking-elimination/)和[急症清单](/catcare/emergency/)。

## 为什么猫这么能忍

猫的祖先独来独往，把病藏起来对活下去有好处（PMC）；Texas A&M 也说，宠物藏起疼痛的本能来自野外生存。所以家猫生病、疼、有压力时，表现出来的很少。再加上猫本来就爱独处、远远看着，主人很难分清是正常还是变了（PMC）。

慢性的疼最容易被忽略。比如关节病，猫常常两边都疼，所以反而不怎么瘸（dvm360）。

## 别这样做

- **以为不瘸、不叫就没事**：长期的疼，表现往往更安静、更难发现（Texas A&M、dvm360）。
- **把变化当成「性格变了」「年纪大了」**：变化不一定是某一种病，但也别默认没事，要查有没有健康原因（PMC）。
- **看它闭着眼，就当它睡得好**：看着在睡，其实可能醒着、在警惕（PMC）。

## 考考自己

1. 它最近不爱跳上沙发了，但走路不瘸，也不叫。不用管？
   - 要留意。不爱跳是慢性疼痛常见的表现，猫常常不瘸也不叫（Texas A&M、dvm360）。找不到原因，就带去看兽医。
2. 要留意的变化，那七个字是什么？
   - 睡、梳、跳、躲、盆、叫、吃。
3. 它老躲在衣柜里，你觉得它只是性格变内向了。对吗？
   - 别急着这么想。躲起来是要留意的变化之一，先查有没有健康原因（PMC、Texas A&M）。
4. 怎么才看得出它变了？
   - 先知道它平时什么样。平时记下来，每周对比一次。

## 细节：来源怎么说

| 类别 | 可能的变化 | 出处 |
| --- | --- | --- |
| 睡眠 | 睡得更多或更少、不安、装睡（看起来在睡，其实醒着在警惕）；睡觉的位置或姿势改变；躺下后找不到舒服的姿势 | PMC 文章；Texas A&M |
| 梳毛 | 变少（可能与肥胖、关节问题有关）或变多（可能与皮肤病、疼痛部位、压力有关）；在一个地方反复舔、咬、抓，或者完全不梳理 | PMC 文章；Texas A&M |
| 藏匿和社交 | 大部分时间躲在床下或衣柜、有其他猫在时躲起来；不愿被抓摸、表情反常 | PMC 文章；Texas A&M |
| 活动和跳跃 | 不愿跳或跳的高度改变、整体活动改变；步态僵硬、不愿上下楼梯、伸懒腰减少、抓挠方式改变 | Texas A&M；dvm360 |
| 食欲和饮水 | 食欲或饮水发生改变 | Texas A&M |
| 砂盆 | 使用变少，尤其是边缘很高的砂盆 | Texas A&M |
| 叫声和表情 | 叫声增多、表情奇怪 | Texas A&M |
| 其他常见病症 | 不吃、呕吐、腹泻或便干、多饮多尿、咳嗽或喘、打喷嚏并有分泌物、耳朦、掉毛、跛行 | Merck（Routine Health Care of Cats） |

来源说的大多是不具体、不显眼的信号，比如活动少了、胃口差了。这些变化往往对不上某一种病，要结合别的检查找原因（PMC）。

慢性疼痛：猫可能表现为不愿跳、换睡觉的位置、躺下后调来调去不舒服（Texas A&M）。

## 存疑点（待问兽医）

1. 绵绵和妙妙平时的睡眠、梳毛、活动和互动，大致算不算正常？
2. 它们在 7 到 9 个月这个阶段，精力旺盛、夜里跑动算不算正常？
3. 两只公猫之间的打闹和真的冲突，怎么区分？
4. 什么程度的变化，建议直接带去看诊，什么程度可以先观察？
5. 兽医检查疼痛时用什么方法，主人在家能学到什么？
6. 国内差异，待核对：国内资料和兽医对猫疼痛和行为变化的说法，以及是否有常用的评估方法。
7. 来源分级：Texas A&M 建议 A，Merck 建议 A，dvm360 建议 B，PMC 待定，都待确认。
8. 核对提醒：PMC 那篇只读到搜索摘要，打开全文被验证码拦住，作者、年份、类型没核实；dvm360 也只读到摘要。要自己打开核对。
9. 细节表里 Merck 那一行的「耳朦」像是错字，要回 Merck 原文核对是什么（耳螨？耳朵有分泌物？）。
