## 记住这三件事

1. **先打电话，再出发。** 医院能在你到之前做好准备（AVMA、Cornell）。
2. **别抱它，用毛巾裹起来，放进航空箱。** 又疼又怕的猫，再温顺也可能咬人（AVMA、iCatCare）。
3. **在家做的急救只是临时的。** 做完都要马上去医院（AVMA）。

## 送医前五步

好记的说法：**一打、二护、三装、四稳、五带。**

| | 做什么 | 出处 |
| --- | --- | --- |
| **一打** | 打电话给兽医或附近的急诊医院，让他们提前准备 | AVMA、Cornell |
| **二护** | 护住自己：别抱它，脸离它的嘴远一点，尽量找人帮忙 | AVMA |
| **三装** | 装进结实的航空箱，最好是上面能打开的。它慌了，就用带家里气味的厚毛巾裹住，又快又轻地放进去 | iCatCare |
| **四稳** | 箱子盖上布，放在脚垫上或用安全带固定，下面垫毛巾；开车稳一点；提箱子托着底，别只拎把手 | iCatCare |
| **五带** | 带上信息：发生了什么、几点开始的、吃了什么、吃了多少、多久之前；带上包装，吐出来或咬过的东西装进密封袋 | AVMA、Cornell |

## 什么时候找兽医

AVMA 列的这些，都要**立刻去最近的兽医院**：

- 伤口大出血
- 像是内出血（见下面「路上要留意」）
- 休克
- 烧伤、眼睛受伤。眼伤会很快变重，可能影响视力。
- 中暑：呼吸很快、流很多口水、虚弱或昏昏欲睡、糊涂、吐或拉、牙龈颜色不对或又干又黏
- 抽搐：24 小时内抽了 2 次以上，一次超过 5 分钟，或者停不下来

只抽了一次、很快停了的，之后也要联系兽医或急诊（AVMA）。

## 路上要留意

出现这些，说明情况很重，路上让它**保持温暖、安静**（AVMA）：

- **休克**：脉搏弱、呼吸浅、紧张不安、眼神发呆。通常发生在重伤或受了大惊吓之后。它要是昏过去了，让它的头和身体保持在一样高。
- **内出血**：鼻子、嘴巴或屁股出血，咳血，尿里有血，牙龈发白，瘫软，脉搏又弱又快。

## 怎么做临时处理

都来自 AVMA，**做完马上去医院**：

| 情况 | 临时处理 | 别这样做 |
| --- | --- | --- |
| 出血 | 用干净的布或毛巾直接按住伤口，用力压 | 至少压 3 分钟再看；血渗透了也别拿掉，在上面再加一层，不然会扯掉刚形成的血块 |
| 可能骨折 | 让它平躺在平的地方，放进航空箱这样的小空间 | 拿不准就别自己包扎、上夹板，做不好反而更伤 |
| 伤口里扎着东西 | 原样送医 | 别自己拔出来 |
| 烧伤 | 用室温的水冲，再盖上用室温水打湿的毛巾 | 冲水会疼，小心被抓咬 |
| 眼睛进了东西 | 看得见异物，就用生理盐水轻轻冲 | 别用手或镊子夹；别让它用爪子揉 |
| 中暑 | 马上降温：挪到阴凉处，用室温水打湿的毛巾敷脖子、腋下、大腿根，几分钟换一次；有风扇就对着吹 | 别把它泡进凉水或冷水里，会更糟 |
| 抽搐 | 把它周围会撞到的东西挪开；看表计时；停下后让它保持温暖、安静 | 别按住它，别吓它想让它停，手别靠近它的嘴 |
| 怀疑中毒 | 立刻打电话。皮肤或眼睛沾了清洁剂，按产品标签上「人沾到了怎么办」来处理 | 别自己催吐，除非兽医让你这么做（Cornell、iCatCare） |

## 平时就准备好

- **存好电话**：自己的兽医、附近的 24 小时急诊（AVMA）。可以存在本站[急症清单](/catcare/emergency/)页的电话栏里，急的时候一点就能打。
- **一份病历**：包括它在吃的药（AVMA）。「[我的猫](/catcare/cats/)」里的记录也能导出，平时的数能帮兽医看出哪里不一样。
- **航空箱当家具**：平时就放在家里，让它在里面睡觉、吃饭，别只在去医院时才拿出来。里面铺它平时睡的垫子和你的旧衣服。出门前至少 15 分钟，在箱子里喷猫用的合成信息素。多带一块垫子，防它路上吐了或弄脏（iCatCare）。
- **急救包**（AVMA 清单里适合猫的部分）：干净的毛巾（用来裹猫）、纱布卷、不粘伤口的敷料或干净布条、自粘绷带、圆头剪刀、一次性手套、小手电、生理盐水、电子体温计。

## 别这样做

- **它受伤了，先抱紧安慰**：AVMA 说别抱受伤的宠物，脸也离它的嘴远一点。
- **在家处理好了，就不去医院**：急救只是临时的，做完都要马上看兽医（AVMA）。
- **压一下就掀开看血止没止住**：至少压 3 分钟；渗透了就往上加，别拿掉（AVMA）。
- **中暑了泡冷水，降温最快**：泡凉水、冷水会更糟（AVMA）。
- **抽搐时按住它、掰开嘴怕它咬舌头**：别按住，手也别靠近它的嘴（AVMA）。
- **拎着航空箱的把手就走**：晃来晃去它更紧张，要托着箱底（iCatCare）。

## 考考自己

1. 送医前五步，那句口诀是什么？
   - 一打、二护、三装、四稳、五带。
2. 它腿上的伤口在流血，你用毛巾压了一会儿，血渗透了。拿掉换一条新的？
   - 别拿掉，在上面再加一层，继续压。拿掉会扯掉刚形成的血块（AVMA）。
3. 大热天它喘得很快、一直流口水，有点站不稳。抱进浴缸泡冷水？
   - 别泡冷水，会更糟。挪到阴凉处，用室温水打湿的毛巾敷脖子、腋下、大腿根，开风扇，同时马上联系医院（AVMA）。
4. 它在抽搐，你怕它咬到舌头。掰开它的嘴？
   - 别。手别靠近它的嘴，也别按住它。把周围的东西挪开，看表计时（AVMA）。

## 细节：来源怎么说

为什么要这么做：

- **先打电话**：医院可以提前准备，你到了就能马上处理（AVMA）。
- **猫会咬人**：受伤带来的疼、怕和慌乱，会让最温顺的宠物也变得难以预料，甚至危险（AVMA）。
- **一定用航空箱**：别让猫在车里乱跑（iCatCare）。受伤的猫待在小空间里，可以减少再次受伤（AVMA）。
- **猫本来就怕去医院**：疼、失去控制、坐车、被关在箱子里逃不掉、陌生的动物和气味，都会让猫紧张（iCatCare）。路上尽量让它平静，对它和对检查都好。

AVMA 的急救包清单里还有活性炭和 3% 双氧水（催吐用），并注明只能在兽医或中毒热线指导下用。Cornell 和 iCatCare 都说别自己催吐，所以没放进上面的急救包。

没有采用：AVMA 页面里的人工呼吸、心脏按压、噎住时抓着猫的后腿甩的做法。光看文字很难做对，做错可能伤到猫。想学的话，请兽医当面教。

「伤口里扎着东西别拔」出自 AVMA 的急救宣传册，其他急救做法出自 AVMA 的网页。
