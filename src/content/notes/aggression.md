## 记住这三件事

1. **先找兽医排除身体原因。** 甲亢、关节炎、牙病都可能让猫变凶（Cornell）。
2. **任何体罚都会让它更怕、更凶。** 打断它、避开诱因、奖励不攻击（Cornell）。
3. **两只猫打架，绝对别伸手去拉。** 用板子、纸箱把它们隔开（Cornell）。

## 怎么看出它要动手了

攻击之前，猫常常已经给过信号（Cornell）。好记的说法：**瞳孔大、尾巴甩、耳朵往后：该停手了。**

都来自 Cornell：

- **要攻击了**：瞳孔放大、耳朵往后压平、尾巴竖起炸毛、弓背。
- **害怕**：瞳孔放大、耳朵压平往外、胡须贴脸或往下压、尾巴紧紧缠着身体或夹在身下、趴着时头抬着。
- **放松**：不挥爪、不哈气，瞳孔正常，耳朵竖着，尾巴自然朝上、不抽动不炸毛。

一只平时温和的猫突然变凶，要想到它可能疼或生病了（Cornell）。更多肢体语言，见[猫的沟通方式与压力信号](/catcare/notes/communication-stress/)。

## 这些情况问问兽医

- **第一步就是兽医**：先排除身体原因，再做行为调整（Cornell）。甲亢、关节炎、牙病、神经系统的问题都可能引起攻击（Cornell），见[甲亢](/catcare/notes/hyperthyroidism/)、[牙周病和口炎](/catcare/notes/dental-disease/)。
- **下面的办法都管不住**：可能要找兽医行为专家（Cornell）。

## 它为什么会攻击

Cornell 分成这几种，一只猫可能同时有好几种：

- **玩过了头**：常见于没跟兄弟姐妹一起长大、或者玩得太少的年轻猫，它没学会「咬太重了」。发动前常甩尾巴、耳朵贴到头顶、瞳孔放大，躲着伏击路过的人。
- **害怕**：碰到陌生的人、动物、声音，或者想起不愉快的事（比如去医院）。耳朵压平、哈气、龇牙、蹲低、尾巴夹着、炸毛。
- **被摸烦了**：原因不清楚，可能是摸得太多受不了，或者想自己决定什么时候停。抱、洗澡、梳毛、剪指甲也可能引起。发作前常瞳孔放大、甩尾巴、耳朵往后。
- **把火撒到你身上**：被什么惹火了又够不着，就转头攻击人或另一只猫。常见诱因：巨响、看到窗外的猫、和家里另一只猫起冲突。
- **身上疼**：怕被碰、被搬动会更疼。比如关节炎的猫被碰到关节，会哈气、咬、抓。
- **争地位**：比如用身子堵门、路过时挥爪拍别的猫。
- **护地盘**：攻击新来的猫，有时是别的动物或人；连住院回来的老成员也可能被攻击。
- **母猫护崽**：刚生完、在喂奶的母猫，会攻击靠近的人。

## 怎么应对

**通用的几条**（Cornell）：

- **越早管越好。**
- **不要体罚**：只会让它更怕、更焦虑，攻击更严重。
- **看到信号就打断**：用不碰到它身体的办法打断它，目的是转移注意力，不是吓唬它。
- **避开你知道会惹它的情况。**
- **用零食奖励它不攻击的时候。**
- 互相攻击的猫先分开，再用奖励慢慢重新介绍。
- 药物可能有帮助，但必须和行为、环境的调整一起用。

**按类型来**（Cornell）：

| 类型 | 怎么做 |
| --- | --- |
| 玩过了头 | 找出规律，提前用玩具引开它，或者不让它去埋伏的地方；可以戴带安全扣的铃铛项圈；扑上来几秒内用声音打断（比如「嘶」一声）；走开不理它，让它知道玩过头就没得玩；逗猫的玩具离手远一点 |
| 害怕 | 找出并避开让它怕的事；避不开就慢慢脱敏：远远地短时间接触，它不攻击就给零食、夸它；不要安慰它，也不要退缩，不理它更好 |
| 被摸烦了 | 不要不请自来地摸它、抱它；它吃饭时别碰；它让你轻轻摸一下、又没有攻击信号时给零食，慢慢延长；一有信号就停，让它冷静；看好小孩，最好别让小孩摸它 |
| 把火撒到你身上 | 去掉或避开诱因，比如拉上窗帘、不让流浪猫靠近窗户、避免家里的猫起冲突 |
| 身上疼 | 别碰疼的地方，和兽医一起止疼 |
| 争地位 | 完全不理它，只在它放松时给关注、陪玩、零食 |
| 护地盘 | 慢慢介绍，别急，见[多猫家庭](/catcare/notes/multi-cat/) |
| 母猫护崽 | 给它安静、少打扰的环境，少来客人，别碰母猫和小猫 |

**两只猫打起来了**：绝对不要把手或身体任何部位伸到中间，你可能伤得很重。可以用婴儿门、纸板、薄木板或塑料板把它们隔开（Cornell）。

## 别这样做

- **它咬人就打它一下**：体罚让它更怕、攻击更严重（Cornell）。
- **用手逗它玩**：玩过头的攻击常见于年轻猫，逗猫的玩具要离手远一点（Cornell）。
- **一直摸到它翻脸**：有的猫被摸着摸着就会突然攻击，留意瞳孔、尾巴、耳朵（Cornell）。
- **它害怕时抱着安慰它**：不理它更好（Cornell）。
- **两只猫打架，伸手去拉**：会被严重抓咬（Cornell）。

## 考考自己

1. 那句好记的话是什么？
   - 瞳孔大、尾巴甩、耳朵往后：该停手了。
2. 它总躲在门后扑你的脚踝。属于哪一种？怎么办？
   - 多半是玩过了头。找出规律，提前用玩具引开它；它扑上来就走开不理它（Cornell）。
3. 一只一向温和的老猫，最近一碰就咬。第一步做什么？
   - 带去看兽医。疼和生病（比如关节炎、甲亢、牙病）都可能让它变凶（Cornell）。
4. 两只猫打成一团，怎么拉开？
   - 别伸手。用纸板、板子、婴儿门把它们隔开（Cornell）。
