## 记住这三件事

1. **先认准「全价」，干的湿的都可以。** iCatCare 一般建议健康的猫干湿都吃一些（iCatCare、Cornell）。
2. **干粮别整天放着让它随便吃。** 这是猫变胖的一大原因（Cornell）。
3. **生肉不推荐。** 没有证据更健康，还有细菌、寄生虫的风险，对猫对人都有（WSAVA、Cornell、Merck）。

## 几种粮怎么选

好记的说法：**干粮省事，湿粮补水，生肉不碰。**

| | 好处 | 要注意 |
| --- | --- | --- |
| **干粮** | 便宜，放着不会坏，方便 | 水只有 6% 到 10%；整天放着随便吃，容易胖；有的猫不太爱吃 |
| **湿粮、罐头** | 水多，补水好；大多数猫爱吃；口味多，挑食的猫也能找到喜欢的；一般蛋白更高、碳水更低 | 通常最贵；开了要放冰箱；有的「美食罐」营养不全，要看是不是全价 |
| **半湿粮** | 价格中等，有的猫更爱吃 | 水约 35%；开封后会变干、变质 |
| **自己做饭** | 无 | 很难配平营养，又费时间；常常缺关键的维生素和矿物质 |
| **生肉**（生骨肉、冻干等） | 脂肪偏高、碳水偏低，可能好消化 | 没有证据比猫粮或配平的熟食更健康；细菌、寄生虫对猫和人都有风险 |

干粮、湿粮、半湿粮出自 Cornell；自己做饭出自 Cornell、iCatCare、Merck；生肉出自 WSAVA、Cornell、Merck。

**为什么建议干湿都吃**：两种的好处都有，也免得猫只认一种（iCatCare）。确定是全价之后，干还是湿可以看猫的喜好（Cornell）。Cornell 的兽医还建议多用罐头：一般蛋白更高、碳水更低、水分多，也更容易按顿喂。

## 生肉为什么不推荐

都来自 WSAVA：

- **没有更健康的证据**：比不过猫粮，也比不过配平的自制熟食。
- **细菌多**：可能带大肠杆菌、沙门氏菌、李斯特菌，感染起来可能很严重，甚至要命，对猫对人都是。
- **家里人也有风险**：处理生肉或猫便时可能被感染。小孩、孕妇、老人、病人更危险，哪怕他们不负责喂猫。
- **冷冻、脱水、冻干，都杀不死所有细菌。**
- **寄生虫**：比如弓形虫，也能传给人；孕妇风险更大，可能影响胎儿。
- **骨头**：可能断牙、堵住食道或肠子、便秘。啃骨头也不能减少牙菌斑和牙周病。
- **营养容易不平衡**：自制的生食、熟食都可能缺或多某些营养，小猫尤其受害，可能长出疼痛的骨骼问题，骨头容易断。

Cornell 和 Merck 也都不推荐给猫喂生肉。

## 怎么存、怎么喂

- **先确认是全价**，再按猫的喜好选干湿，见[看懂成分表](/catcare/notes/food-labels/)。
- **干粮**：放阴凉干燥处的密封容器里，过期别喂（Cornell）。
- **罐头**：没吃完的放冰箱（Cornell）。猫喜欢接近体温（大约 35°C）的食物，稍微温一下更香（iCatCare）。
- **按顿喂**：别整天放一大盆干粮，见[喂食方式和饮水](/catcare/notes/feeding-water/)。

## 这些情况问问兽医

- **因为治病要自己做饭**：请兽医推荐，最好由兽医营养师设计配方（Cornell、Merck）。
- **家里有孕妇、小孩、老人或免疫力弱的人**：更不要喂生肉（WSAVA）。
- **换了生肉或高脂的饮食后拉肚子**：高脂、低纤维的饮食，不管生熟，有的猫会拉肚子，甚至得胰腺炎（WSAVA）。
- **吃了某种食物后吐、拉**：按[急症清单](/catcare/emergency/)判断多急。

## 别这样做

- **觉得生骨肉更天然、更健康**：没有证据，还有细菌和寄生虫的风险（WSAVA、Cornell、Merck）。
- **觉得冻干的生肉就安全了**：冻干杀不死所有细菌（WSAVA）。
- **觉得啃骨头能清洁牙齿**：不能，还可能断牙、堵肠子（WSAVA）。
- **觉得自己做的饭最放心**：营养很难配平（iCatCare、Merck）。
- **只喂干粮或只喂湿粮**：iCatCare 一般建议两种都吃。
- **给猫喝牛奶**：可能让它肠胃不舒服（Merck）。

## 考考自己

1. 那句好记的话是什么？
   - 干粮省事，湿粮补水，生肉不碰。
2. 冻干生肉经过冷冻干燥，细菌就没了吧？
   - 不是。冷冻、脱水、冻干都杀不死所有细菌（WSAVA）。
3. 家里有孕妇，能喂生骨肉吗？
   - 更不要。处理生肉和猫便时可能感染细菌、弓形虫，孕妇风险更大（WSAVA）。
4. 罐头开了没吃完，怎么办？
   - 放冰箱。下次喂之前稍微温一下，猫更爱吃（Cornell、iCatCare）。

## 细节：来源怎么说

罐头的含水量，Cornell 不同页面写的不一样：喂养页说「至少 75%」，饮水页说「最高约 80%」，肥胖页说「90%」。总之远高于干粮的 6% 到 10%。

干粮看原料质量，可能没那么好消化（Cornell）。有些「美食罐」营养不全，要看营养声明（Cornell）。

吃湿粮的猫喝水可能少一些，吃干粮的猫主要靠喝水（Cornell）。

WSAVA 说的骨骼问题：自制饮食营养不平衡，对小猫尤其有害，可能导致疼痛的骨骼问题和病理性骨折。
