## 1. 一天喂几顿（带出处）

| 来源 | 建议 |
| --- | --- |
| iCatCare | 尽量少量多餐：把一天的量分成至少 5 份，在 24 小时里喂完，可以用定时喂食器和益智喂食器 |
| Merck | 猫一般喜欢少量多餐；大多数猫一天喂两次就能吃得开心、体重合适；可以用自动喂食器控制每天的量 |
| AAFP 喂养共识 | 少量多餐、合适的益智喂食器、把食物放在不同地方让猫"找"、多设几个吃饭喝水的点，有时用自动喂食器；方案要按每个家庭来定 |

**三家都不推荐**：一个食盆整天放满粮随便吃（Merck 说容易吃多、导致肥胖），或者每天只给一两顿很好吃的大餐（AAFP）。

**小猫**：4 个月以下一天喂 3 到 4 次小猫粮，之后慢慢减少次数（Merck）。

## 2. 为什么"怎么喂"这么重要

- **符合天性**：野外的猫一天里少量多次地吃，野猫每天要花 12 个小时以上找吃的、抓猎物（iCatCare）。
- **防止无聊和压力**：每天在同一个地方、从碗里吃，不用费任何力气，尤其是室内猫，可能会无聊、焦虑、沮丧（iCatCare）。AAFP 说让猫有正常的进食行为，可以帮助预防膀胱炎这类和压力有关的问题，以及肥胖。
- **防止吃多**：随时都能吃，猫可能吃多（iCatCare、Merck）。
- **多猫家庭**：胆小的猫可能为了躲开别的动物，吃得不够、变瘦（AAFP）。

## 3. 喂多少

WSAVA 给的健康成年猫（体型理想）每天大概需要的热量，只是参考，每只猫不一样：

| 体重 | 每天热量（千卡） |
| --- | --- |
| 2 公斤 | 160–170 |
| 3 公斤 | 200–210 |
| 4 公斤 | 225–250 |
| 5 公斤 | 250–290 |
| 6 公斤 | 265–330 |

- **先按包装上的建议量作为起点，再根据体重和体型调整**（iCatCare）。
- **干粮要称**：干粮能量密度很高，合适的量看起来很少；称一下只多花两分钟，却可能帮猫多活几年（iCatCare）。
- **零食**：不超过每天热量的 10% 到 15%（Cornell）。
- 这张表是成年猫的，小猫需要更多营养，问兽医。

## 4. 喝水

**每天大概要多少水**：Cornell 说每 5 磅（约 2.3 公斤）瘦体重每天大约 4 盎司（约 120 毫升），包括食物里的水分。吃湿粮的猫可能喝得少。详见《吃喝拉撒的正常范围与异常信号》。

**怎么让猫多喝**（iCatCare）：

| 方面 | 做法 |
| --- | --- |
| 碗 | 一般喜欢玻璃或陶瓷碗，不喜欢塑料碗；宽而浅，不用把头伸进去，胡须也不会碰到碗边；**装满到碗沿**；关节不好的猫用垫高的碗 |
| 数量 | 多放几个，每层楼都有；多猫家庭**每只猫至少一个，再多一个** |
| 位置 | 离食盆远一点（猫不喜欢在食物旁边喝水）；安静的地方，远离常开的门和洗衣机；不要贴墙放，让猫能从四面喝；不要用水和粮连在一起的双碗 |
| 流动的水 | 宠物饮水机（慢慢引入）、滴水的龙头、在大碗里放一个乒乓球让水动起来 |
| 换种水试试 | 自来水（能直接给人喝的）、接的雨水、不含气的泉水、过滤水 |
| 加点味道 | 无盐煮鸡肉或鱼的汤、泉水浸金枪鱼罐头的汁、冻成冰块的金枪鱼水；湿粮里加一点水 |
| 不要给 | 咸的汤汁、卤汁、肉汁；牛奶（猫消化不了，可能腹泻）；任何含洋葱或洋葱粉的东西（洋葱对猫有毒） |
| 其他 | 用室温的水（冷的味道淡）；喂湿粮（换粮前问兽医） |

**哪些猫特别需要多喝水**（iCatCare）：有肾病、特发性膀胱炎、尿结石、糖尿病的猫，以及在吃某些药（比如非甾体抗炎药）的猫。

## 5. 就医红线

- **超过一天不吃东西：马上带去看兽医**（Merck）。吃得不够也可能是生病了。
- **喝水和尿明显变多：联系兽医**（Merck）。不要自己限制喝水，见《急症清单》。

## 6. 家里能做什么

**益智喂食器**（iCatCare）：

- 可以买，也可以自己做：干粮放进鸡蛋盒，湿粮放进硅胶冰格。
- 慢慢引入：一开始只放一部分粮，其余照常放碗里；先调到最容易拿出来的难度；用透明、开口多的，让猫看得见、闻得到；在周围撒几粒干粮引起兴趣。
- 猫用熟练、没有紧张或沮丧的样子后，再慢慢增加用喂食器喂的比例。iCatCare 建议条件合适时，可以全部用益智喂食器喂。
- 玩腻了就加难度：换地方藏、减少或缩小出粮孔、换一种需要不同动作的喂食器。

**吃饭的地方**：

- 猫喜欢独自吃饭，放在安静、不被打扰的地方；多宠家庭分开设吃饭的点，减少压力和抢食（Merck）。
- 猫喜欢用浅碗或浅盘吃饭，吃的时候能看到周围，胡须不碰碗边；用玻璃或陶瓷碗比塑料碗好，塑料碗容易留味（iCatCare）。
- 每天清洗水碗，随时有几碗干净的新鲜水（Merck）。

## 7. 常见误区

- **整天放一盆干粮最省事**：容易吃多、发胖（Merck、Cornell）。
- **猫喝水少，给它喝牛奶**：牛奶可能导致腹泻（iCatCare）。
- **用肉汤给猫调味**：咸的汤汁、含洋葱的高汤都不行（iCatCare）。
- **水碗放在食盆旁边方便**：猫不喜欢在食物旁边喝水，双碗会让它喝得更少（iCatCare）。
- **两只猫用一个水碗就够**：每只猫至少一个，再多一个（iCatCare）。
