## 记住这三件事

1. **别整天放一大盆粮。** 随时能吃，容易吃多、发胖（Merck、Cornell）。分顿喂，或者用益智喂食器（iCatCare、AAFP）。
2. **干粮要称，别估。** 合适的量看起来很少；称一下只多花两分钟，却可能帮它多活几年（iCatCare）。
3. **水碗宽、浅、装满，离食盆远一点，多放几个。** 猫不喜欢在吃的旁边喝水（iCatCare）。

## 一天喂几顿

好记的说法：**少量多餐，别放满盆。**

- **iCatCare**：尽量少量多餐。一天的量分成至少 5 份，24 小时里喂完，可以用定时喂食器、益智喂食器。
- **Merck**：大多数猫一天喂两顿，就能吃得开心、体重合适。可以用自动喂食器控制一天的量。
- **AAFP**：少量多餐，用益智喂食器，把吃的藏在不同地方让它「找」，多设几个吃饭喝水的点。方案按每家的情况定。

几家说的顿数不一样，但都不推荐：一盆粮整天放满随便吃，或者一天只给一两顿特别好吃的大餐（Merck、AAFP）。

**小猫**：4 个月以下一天喂 3 到 4 次小猫粮，之后慢慢减少次数（Merck）。

**为什么要这样喂**：

- 野外的猫一天里少量多次地吃，每天要花 12 个小时以上找吃的、抓猎物（iCatCare）。
- 每天在同一个碗里、不费力气就吃到，室内猫容易无聊、焦虑（iCatCare）。让猫像猫一样吃饭，能帮着预防膀胱炎这类和压力有关的病，还有肥胖（AAFP）。
- 多猫家庭，胆小的猫可能为了躲别的猫，吃不够、变瘦（AAFP）。

## 喂多少

| 体重 | 每天热量（千卡） |
| --- | --- |
| 2 公斤 | 160–170 |
| 3 公斤 | 200–210 |
| 4 公斤 | 225–250 |
| 5 公斤 | 250–290 |
| 6 公斤 | 265–330 |

- **先按包装上的建议量开始，再看体重和体型调整**（iCatCare）。
- **零食**不超过每天热量的 10% 到 15%（Cornell）。

## 怎么让它多喝水

一天大概要多少水，见[吃喝拉撒](/catcare/notes/eating-drinking-elimination/)里的计算器。下面的做法都来自 iCatCare：

| 方面 | 做法 |
| --- | --- |
| **碗** | 玻璃或陶瓷碗，别用塑料碗；宽而浅，胡须碰不到碗边；装满到碗沿；关节不好的猫用垫高的碗 |
| **数量** | 多放几个，每层楼都有；多猫家庭每只猫至少一个，再多一个 |
| **位置** | 离食盆远一点；放在安静的地方，远离常开的门和洗衣机；别贴墙放，让它能从四面喝；别用水和粮连在一起的双碗 |
| **流动的水** | 宠物饮水机（慢慢引入）、滴水的龙头、大碗里放一个乒乓球让水动起来 |
| **换种水试试** | 能直接喝的自来水、接的雨水、不含气的泉水、过滤水 |
| **加点味道** | 无盐煮鸡肉或鱼的汤、泉水浸金枪鱼罐头的汁、冻成冰块的金枪鱼水；湿粮里加一点水 |
| **别给** | 咸的汤汁、卤汁、肉汁；牛奶（猫消化不了，可能拉肚子）；任何含洋葱或洋葱粉的东西（洋葱对猫有毒） |
| **其他** | 用室温的水，冷水味道淡；喂湿粮（换粮前问兽医） |

**特别需要多喝水的猫**：有肾病、特发性膀胱炎、尿结石、糖尿病的，以及在吃某些药（比如非甾体抗炎药）的（iCatCare）。

## 怎么用益智喂食器

都来自 iCatCare：

1. **买或自己做**：干粮放进鸡蛋盒，湿粮放进硅胶冰格。
2. **慢慢引入**：一开始只放一部分粮，其余照常放碗里。先调到最容易拿出来的难度；用透明、开口多的，让它看得见、闻得到；周围撒几粒干粮勾起兴趣。
3. **慢慢加量**：它用熟了、没有紧张或烦躁的样子，再慢慢增加喂食器喂的比例。条件合适的话，可以全部用益智喂食器喂。
4. **玩腻了就加难度**：换地方藏、减少或缩小出粮孔、换一种要不同动作的喂食器。

**吃饭的地方**：猫喜欢独自吃饭，放在安静、没人打扰的地方；多宠家庭分开设吃饭的点（Merck）。用浅碗或浅盘，吃的时候能看到周围，胡须不碰碗边；塑料碗容易留味（iCatCare）。水碗每天洗（Merck）。

## 什么时候找兽医

- **超过一天不吃：马上带去看兽医**（Merck）。吃得少，也可能是生病了。
- **喝水、尿量明显变多：联系兽医**（Merck）。别自己限制它喝水，见[急症清单](/catcare/emergency/)。

## 别这样做

- **整天放一盆干粮最省事**：容易吃多、发胖（Merck、Cornell）。
- **它喝水少，就给它喝牛奶**：牛奶可能让它拉肚子（iCatCare）。
- **用咸肉汤、带洋葱的高汤调味**：都不行（iCatCare）。
- **水碗放在食盆旁边**：猫不喜欢在吃的旁边喝水，双碗会让它喝得更少（iCatCare）。
- **两只猫用一个水碗**：每只猫至少一个，再多一个（iCatCare）。

## 考考自己

1. 那句好记的话是什么？
   - 少量多餐，别放满盆。
2. 家里两只猫，至少要几个水碗？
   - 3 个。每只猫至少一个，再多一个（iCatCare）。
3. 想让它多喝水，在水里加点自己喝剩的鸡汤行吗？
   - 别加。咸的汤汁、含洋葱的高汤都不行。可以用无盐煮鸡肉的汤（iCatCare）。
4. 干粮量了一杯，看起来好少，再多加点？
   - 别加。干粮能量很高，合适的量看起来就是很少。用秤称，别靠眼睛估（iCatCare）。

## 细节：来源怎么说

| 来源 | 一天几顿 |
| --- | --- |
| iCatCare | 尽量少量多餐：把一天的量分成至少 5 份，在 24 小时里喂完，可以用定时喂食器和益智喂食器 |
| Merck | 猫一般喜欢少量多餐；大多数猫一天喂两次就能吃得开心、体重合适；可以用自动喂食器控制每天的量 |
| AAFP 喂养共识 | 少量多餐、合适的益智喂食器、把食物放在不同地方让猫「找」、多设几个吃饭喝水的点，有时用自动喂食器；方案要按每个家庭来定 |

iCatCare 和 Merck 对「一天几顿」的建议不一样，这里两种都列出来。

喝水量：Cornell 说每 5 磅（约 2.3 公斤）瘦体重每天大约 4 盎司（约 120 毫升），包括食物里的水分。
